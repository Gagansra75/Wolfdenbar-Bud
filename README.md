## 🚀 Getting Started

### Step 1: Add Your Images and Videos

The website needs the actual images and videos from your live site. Follow these instructions:

1. Go to the `images/` folder
2. Read the `images/README.md` file for the complete list of required files
3. Download images from wolfdenbar.com and place them in the `images/` folder

**Required files:**
- hero-video.mp4 (hero section background)
- Burger_Photo.jpg, Cocktail_Photo.jpg, dis_Photo.jpg, cock_mock_photo.jpg, Mix_Photo.jpg, mocktail_photo.jpg, Mug_Photo.jpg, Bar_Photo.jpg, Friday_Photo.jpg (gallery)
- slide1.jpg, slide2.jpg, slide3.jpg (slideshow)

### Step 2: Open the Website

Simply open `index.html` in your web browser:
- Double-click the `index.html` file, OR
- Right-click → Open With → Your preferred browser

### Step 3: Test Functionality

Make sure to test:
- Mobile menu (resize browser window)
- Slideshow navigation
- Reviews carousel
- Newsletter form
- All links and navigation

## 🔧 Troubleshooting

### Images Not Showing
- Check that image files are in the `images/` folder
- Verify filenames match exactly (case-sensitive)
- Ensure image format is correct (JPG, PNG, or MP4 for video)

### Video Not Playing
- Make sure the video file is named `hero-video.mp4`
- Video should be in MP4 format
- Try a different browser if autoplay is blocked

### Mobile Menu Not Working
- Clear browser cache and refresh
- Check browser console for JavaScript errors (F12)
